# plans/

Feature plans produced by the **Planner** agent. One file per slug, plus a rolling status file maintained by **Project Flow**.

- `<slug>.md` — the plan: goal, decomposed steps, risks, acceptance criteria.
- `<slug>-retro.md` — short retrospective written by **Project Flow** on close-out.
- `_status.md` — current workflow status across all in-flight plans.

Plans are revised by appending dated revision sections, not by overwriting.
